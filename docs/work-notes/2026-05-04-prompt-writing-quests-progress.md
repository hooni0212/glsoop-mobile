# 프롬프트 글쓰기 퀘스트 모바일 진행 현황

작성일: 2026-05-04

## 범위

- 성장 홈에서 중복되는 인기글 영역을 제거하고 캠페인 중심으로 정리한다.
- 프롬프트형 퀘스트에서 글쓰기 화면으로 자연스럽게 진입하게 한다.
- 퀘스트 완료 글 작성 시 서버에 `quest_context`를 전송한다.

## 완료된 작업

- 성장 홈의 인기글 섹션을 제거하고 진행 캠페인 미리보기 섹션을 추가했다.
- 퀘스트 화면에서 `PROMPT_POST_CREATED` 퀘스트의 글감 카드와 글쓰기 CTA를 보여준다.
- 프롬프트 퀘스트 진입 시 글쓰기 화면으로 `questStateId`, `promptKey`, 주제, 본문, 기본 카테고리, 추천 해시태그를 전달한다.
- 글쓰기 화면에서 퀘스트 주제 카드를 표시하고 기본 카테고리/해시태그를 자동 반영한다.
- 글 작성 요청에 `quest_context`를 포함하고, 완료 응답이 있으면 성공 메시지에 퀘스트 반영 상태를 보여준다.
- 임시저장 데이터에 퀘스트 문맥을 포함해 작성 중 이탈 후 복구할 수 있게 했다.
- 퀘스트 보상 코스메틱 preview chip을 추가해 시즌 배지/스티커 보상을 미리 보여준다.
- 성장 플로우 E2E를 캠페인 중심 홈과 프롬프트 퀘스트 글쓰기 흐름에 맞게 갱신했다.

## 남은 판단

- 업적 화면은 아직 하이라이트/목록 중심이고, 업적별 보상 배지 수집 경험이 부족하다.
- 프로필 꾸미기 화면은 대표 뱃지, 쇼케이스 뱃지, 헤더 스티커까지만 지원한다.
- 특별 배경은 모바일 타입, API 서비스, 프로필 미리보기, 공개 프로필 렌더링이 모두 추가되어야 한다.
- 설치 앱에서 프로필 꾸미기가 실패하는 경우 production API base와 원격 DB seed 상태를 먼저 확인해야 한다.

## 검증 상태

- 브랜치 정리 전에 lint/typecheck와 성장 플로우 E2E를 재실행한다.
- 병합 후 새 브랜치에서 업적 페이지와 프로필 꾸미기 개편 문서를 이어 작성한다.
