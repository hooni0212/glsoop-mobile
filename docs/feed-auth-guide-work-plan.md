## 구현 메모

- 기존 전역 `AuthGate`는 저장, 성장, 내 정보, 글쓰기, 계정 센터 등 라우트 단위 보호를 이미 처리한다.
- 홈 내부의 `팔로잉` 피드는 같은 공개 홈 화면 안의 기능이므로 별도 클릭 가드가 필요하다.
- 모바일 추천 피드는 서버의 단일 `recommended` 정렬에 의존하지 않고 `popular/latest` 풀을 함께 가져와 다양성 기준으로 섞는다.
- 기존 `인기` 탭은 최신순 성격에 맞춰 `최신` 탭으로 바꿨다.
- 검증: `npm run typecheck`, `npm run lint`, `npx playwright test e2e/home.spec.ts e2e/post-detail.spec.ts e2e/auth-session-web.spec.ts` 통과.
- 추가 수정에서는 `/guide` 라우트를 제거하고 `AuthWelcome`을 온보딩 화면으로 사용한다.
